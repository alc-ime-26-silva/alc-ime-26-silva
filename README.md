# alc-ime-26-silva

Códigos em Python da disciplina **EE 600200 – Álgebra Linear Computacional**, do Instituto Militar de Engenharia (IME), 2026.

Aluno: Itair Silva Rodrigues

## Arquivos

| Arquivo | Lista | Questão | O que faz |
|---|---|---|---|
| `lista1_q4_substituicao_regressiva.py` | 1 | 4 | Resolve `U x = b` por substituição regressiva, com exceção se houver zero na diagonal de `U` |
| `lista1_q5_robo_planar.py` | 1 | 5 | Calcula a posição do efetuador de um robô planar de dois elos a partir dos ângulos das juntas |
| `lista2_q4_posto_e_norma_uvT.py` | 2 | 4 | Exercício 7.32 de [FORD]: posto e norma-2 de `u v^T` para vetores aleatórios |
| `lista2_q5_matriz_ortogonal.py` | 2 | 5 | Exercícios 6.38 e 6.39 de [FORD]: testa se uma matriz é ortogonal pela definição e pelos vetores coluna |

## Como executar

É necessário ter Python 3 e a biblioteca NumPy:

```
pip install numpy
```

Depois, basta rodar o arquivo desejado, por exemplo:

```
python lista1_q4_substituicao_regressiva.py
```
